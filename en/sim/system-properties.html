Memoryless? Heuristic test: checks whether y(t) depends only on the current value of x(t).

A system is classified as memoryless when its output depends solely on the present value x(t) and on no other time instants (e.g., 3*x(t), x(t)^2). When the expression contains x(t-a) ($a \neq 0$), an integral or a differential term, the system is said to possess memory.

Causal? When the portion of the input for t>t* is removed, does the output for t<t* change?

Test (a necessary and sufficient condition): the input is split into two copies at $t^*$. If $T\{x\}(t) = T\{x \cdot u(t^*-t)\}(t)$ holds for all $t \leq t^*$, the system is regarded as causal, since in this case the past of the output depends only on the past of the input. In systems that access the future, such as x(t+a) ($a > 0$), x(-t) or x(2t), the pink (dashed) output of the test diverges from the principal response (green) over the past portion of the time axis.

Linear? If the two outputs (green = T{combined}, pink-dashed = a·T{x₁}+b·T{x₂}) coincide, superposition holds.

Two fundamental tests are applied: (a) Additivity — $T\{x_1+x_2\} = T\{x_1\} + T\{x_2\}$; (b) Homogeneity — $T\{\alpha x\} = \alpha T\{x\}$. When both conditions are satisfied simultaneously, the system is regarded as linear.

Time-invariant? If the green curve (delay first, then system) and the pink-dashed curve (system first, then delay) coincide, the system is time-invariant.

For a system to be regarded as time-invariant, a delay applied to the input must appear as the same delay in the output. Systems that explicitly involve $t$, such as t*x(t), x(2t) or cos(2\pi t)\cdot x(t)$, are generally classified as time-varying.

BIBO stable? A bounded input must produce a bounded output.

A proof of BIBO stability requires that every bounded input produces a bounded output; observation with a single bounded input can only serve to provide a counter-example. Despite this limitation, if the output is found to grow without bound, the system is classified as unstable. In systems containing the term e^(\alpha t), a value $\alpha > 0$ leads to instability.

★Impulse Response (LTI systems only)
h(t) = T{δ(t − th)}
LTI status: h(t) is computed when both the linearity and time invariance tests pass.

Input δ(t − th) unit impulse

→

Output h(t) impulse response

LTI systems are completely characterised by their impulse response $h(t)$: for an arbitrary input, the output is obtained through the convolution $y(t) = x(t) * h(t) = \int x(\tau)\,h(t-\tau)\,d\tau$. When the system is not LTI, this representation ceases to be valid, since a distinct $h(\cdot)$ would be required for each input.
